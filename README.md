# A Day of One-Line Pitches

One sentence, 161 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

> Got an app idea but never coded? Just describe it in plain words — an AI agent builds your first app on make.fun, free to enter, and it could even win you money.

`main.py` (Python 3.13, standard library only) writes that sentence to `/output/entry.txt`. It is fixed text, so every run produces the exact same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
